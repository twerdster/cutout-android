These files were retrieved on 2026-11-13 to accompany notices in the recovered Android source. They were not present as standalone files in Elad Richardson's archive and do not change the original source bytes or assign a license to the repository as a whole.

- [ANN license](ANN-LICENSE.txt) and [copyright](ANN-COPYRIGHT.txt), from David Mount's University of Maryland ANN site. The upstream license document contains LGPL 2.1 and states its scope as all ANN versions. This does not assert that CutOut's ANN copy is an unmodified 1.1.2 release.
- [LGPL 2.1](LGPL-2.1.txt), from GNU, accompanying FIGTree's 2.1-or-later notices.
- [Apache 2.0](Apache-2.0.txt), from the Apache Software Foundation, accompanying the AOSP `Exif.java` notice.
- [MegaWave2 public license](MegaWave2-LICENSE.txt) and [copyright](MegaWave2-COPYRIGHT.txt), from a pinned revision of the MegaWave source mirror, covering its stated 2.x/3.x scope. These references supplement the retained module/system notices; they do not identify an exact upstream revision for CutOut's adapted files.

[SOURCES.json](SOURCES.json) records each retrieval URL, date, byte count and SHA-256. Luke Hutchison's complete MIT notice remains in the original Java files. Other unresolved notice or permission details are recorded in the [Android guide](../original-android.md#attribution-and-terms).
