CutOut

Draw foreground and background scribbles to extract an object. This local interface runs the recovered C++ segmentation code with updated build and input handling.

Choose an image or load the example. Mark the object in green and the background in red.

Image and scribbles

Click or drag to draw. Uploads are resized to at most 1,600 pixels on their longest side. The native pipeline normally segments at 400 pixels before restoring the output size.
