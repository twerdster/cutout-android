## Updated work

**[Open the browser demo](https://twerdster.github.io/cutout-android/)**

The **browser application** runs the C++17 port of the recovered algorithms locally in WebAssembly. Load an image, mark foreground and background, run segmentation and download the mask or transparent PNG.

[Detailed implementation, setup and recorded results](DETAILS.md).

Historical project: Elad Richardson; supervision: Anastasia Dubrovina and Aaron Wetzler. New implementations are labeled separately and do not change the preserved materials.

Checked in Chrome at desktop and phone-sized layouts; physical phone browsers and other browsers are untested.
