CutOut — recovered implementation and updated runner

Original Android implementation: Elad Richardson. The historical project summary and poster credit supervision by Anastasia Dubrovina and Aaron Wetzler. The original application's About text credits Elad Richardson, Anastasia Dubrovina and Ron Kimmel, lists Aaron Wetzler for additional technical supervision, and credits Michal Hendel's help with interface and logo design.

This browser interface, WebAssembly boundary and separately labeled native restoration were prepared in 2026 by Codex for Aaron Wetzler. The recovered original is preserved separately; new fixes and interface changes are updated work, not presented as Elad's original code.
