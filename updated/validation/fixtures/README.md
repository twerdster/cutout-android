# Photograph fixture

`coffee.png` is the unchanged 600 × 400 scikit-image v0.25.2 coffee photograph, by Rachel Michetti and courtesy of Pikolo Espresso Bar. The [scikit-image data documentation](https://scikit-image.org/docs/0.25.x/api/skimage.data.html#skimage.data.coffee) identifies it as CC0; see the [CC0 dedication](https://creativecommons.org/publicdomain/zero/1.0/). [PROVENANCE.json](PROVENANCE.json) records the download URL and SHA-256.

`coffee-scribbles.json` contains foreground and background strokes authored in 2026 by Codex for Aaron Wetzler. The requested foreground includes the cup, saucer and spoon. The file uses zero-based image coordinates `[x, y]` and a brush radius in pixels. It is an execution example on a photograph, without an independent reference mask. Scribble agreement, finite output and repeatability checks do not measure photographic segmentation accuracy.
